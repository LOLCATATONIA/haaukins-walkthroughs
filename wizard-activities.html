Wizard Activities

"Do some magic to repair the file" = ret de ødelagte PNG-magic-bytes.

ForensicsHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Hvad går opgaven ud på?

Filen 02-m4g1c.png (fra DCIS-OSINT-bundtet — samme bundt som Broken but not Lost) kan ikke åbnes. file siger blot data — ingen genkendt filtype:

file 02-m4g1c.png          # -> data (ingen magic match)
xxd 02-m4g1c.png | head -1  # -> 7772 6f6e 6720 7864 ...  = "wrong xd"

De første 8 bytes (PNG-signaturen) er overskrevet med den bogstavelige tekst wrong xd. Resten af strukturen (IHDR-chunk osv.) er intakt.

Trin for trin

En PNG starter altid med signaturen 89 50 4E 47 0D 0A 1A 0A. Skriv de 8 bytes tilbage:

python3 - <<'PY'
d = bytearray(open("02-m4g1c.png","rb").read())
d[:8] = bytes([0x89,0x50,0x4e,0x47,0x0d,0x0a,0x1a,0x0a])
open("fixed.png","wb").write(d)
PY
file fixed.png             # -> PNG image data, 3648 x 2432

Åbn fixed.png — flaget står skrevet direkte i billedet.

🚩 Vis løsning & eksempel-flag

Flag: HKN{m4g1c_h3ed3rs} ("magic headers" — netop det du rettede).

Hvad du har lært

  • PNG-signaturen er altid 89 50 4E 47 0D 0A 1A 0A — ret den og filen lever igen.
  • Samme klasse som Concealed Conversation (én ødelagt signatur-byte); her er alle 8 overskrevet.
  • file siger "data" = magic bytes matcher intet kendt format → mistænk en overskrevet header.
