Covert Channels: TCP

Data skjult i TCP-headerens ubrugte reserverede bits.

ForensicsHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Hvad går opgaven ud på?

Alle tre opgaver løses på samme capture.pcap. Start altid med protokol-hierarkiet, og saml bits/bytes i kronologisk rækkefølge:

tshark -r capture.pcap -q -z io,phs

67 SYN-pakker der aldrig får svar. ISN/vindue/IP-ID var støj — men de 3 reserverede bits i TCP-flags (skal være 0 pr. RFC) varierede.

Trin for trin

tshark -r capture.pcap -Y 'tcp.flags.syn==1 && tcp.flags.ack==0 && ip.dst==18.157.68.73' \
  -T fields -e frame.number -e tcp.flags

tcp.flags er hele flags-byten som hex, fx 0x0e02. De 3 reserverede bits sidder på plads 9-11, så du trækker dem ud med en maske og et skift. Saml dem fra alle 67 pakker i kronologisk rækkefølge og del i 8-bit grupper:

python3 -c "
rows = [(123, 0x0e02), (124, 0x0402)]   # (frame.number, int(tcp.flags, 16)) for hver pakke, i rækkefølge
bits = ''.join(format((flags & 0xe00) >> 9, '03b') for _, flags in rows)
chars = [chr(int(bits[i:i+8], 2)) for i in range(0, len(bits) - 7, 8)]
print(''.join(chars))"

67 pakker × 3 bit = 201 bit = 25 hele bytes. Med alle 67 rækker fra den rigtige fangst giver det flaget.

🚩 Vis løsning & eksempel-flag

Flag: HKN{unus3d_r35erv3d_b1ts}

Hvad du har lært

  • Skjulte data kan bo i reserverede/ubrugte bits, IP-ID, sequence numbers eller pakke-timing.
  • Opgaveteksten pegede på feltet (’those SYN packets seem off’).
