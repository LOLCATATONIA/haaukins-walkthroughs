Covert Channels: TCP

Data skjult i TCP-headerens ubrugte reserverede bits.

ForensicsHaaukins CTF
🎓 Prøv selv først. Trinnene viser metoden, det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Hvad går opgaven ud på?

Alle tre opgaver løses på samme capture.pcap. Start altid med protokol-hierarkiet, og saml bits/bytes i kronologisk rækkefølge:

tshark -r capture.pcap -q -z io,phs

67 SYN-pakker der aldrig får svar. ISN/vindue/IP-ID var støj, men de 3 reserverede bits i TCP-flags (skal være 0 pr. RFC) varierede.

Trin for trin

tshark -r capture.pcap -Y 'tcp.flags.syn==1 && tcp.flags.ack==0 && ip.dst==18.157.68.73' \
  -T fields -e frame.number -e tcp.flags

tcp.flags er hele flags-byten som hex, fx 0x0e02. De 3 reserverede bits sidder på plads 9-11, så du trækker dem ud med masken 0xe00 og et skift. Gem flag-feltet for alle 67 pakker (kronologisk) og afkod direkte fra filen, så der ikke skal indsættes rækker i hånden:

tshark -r capture.pcap -Y 'tcp.flags.syn==1 && tcp.flags.ack==0 && ip.dst==18.157.68.73' \
  -T fields -e tcp.flags > flags.txt        # 67 linjer, én pr. pakke
python3 -c "
flags = [int(l, 16) for l in open('flags.txt')]
bits  = ''.join(format((f & 0xe00) >> 9, '03b') for f in flags)
print(''.join(chr(int(bits[i:i+8], 2)) for i in range(0, len(bits) - 7, 8)))"

67 pakker × 3 bit = 201 bit = 25 hele bytes → HKN{unus3d_r35erv3d_b1ts}.

🚩 Vis løsning & eksempel-flag

Flag: HKN{unus3d_r35erv3d_b1ts}

Hvad du har lært

  • Skjulte data kan bo i reserverede/ubrugte bits, IP-ID, sequence numbers eller pakke-timing.
  • Opgaveteksten pegede på feltet (’those SYN packets seem off’).

Hvor ses dette igen?

Protokol-felter der "skal" være nul eller ignoreres (TCP's reserverede bits, IP-ID, padding-bytes) er oplagte skjulesteder, fordi normale systemer aldrig kigger på dem. Endnu mere subtilt kan data ligge i TIMING mellem pakker, ikke i indholdet overhovedet. Når ingen af de synlige felter bærer et mønster, så spørg: hvad ved denne protokol har jeg endnu ikke kigget på, inklusive det der burde være betydningsløst?
