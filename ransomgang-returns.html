RansomGang Returns

"No section header" = UPX-packing; login-koden kommer fra et seed serveren selv lækker.

Reverse EngineeringHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.
📚 Baggrund: denne opgave bygger på en fælles teknik — læs primeren: Kom i gang: VPN, Hosts og lab-opsætning.

'The new trick' = UPX, ikke rigtig stripping

Binæren ser statisk linket + uden section headers ud (ligner stripping). Men:

grep -a UPX ransomgangreturns      # -> "UPX 3.96"-signatur
upx -d ransomgangreturns -o unpacked   # udpakket = unstripped MED fuld debug-info

Tjek altid for en packer-signatur før manuel symbol-fri RE.

Login-logikken (statisk på den udpakkede binær)

En tråd beregner login-koden ud fra boot-epoch'en — som printes direkte i banneret:

srandom(epoch); r1=rand(); r2=rand();
kode = epoch - (r1 % 10000) + (r2 % 10000);

Da epoch'en lækkes til klienten, kan hele random()-sekvensen genskabes 100% deterministisk. Men: Pythons random (Mersenne Twister) matcher ikke glibc — du skal genimplementere glibc's egen TYPE_3 additive generator (31-ords cirkulær buffer, separation 3):

def glibc_random(seed):
    deg, sep = 31, 3
    r = [0] * deg
    word = seed & 0xffffffff
    if word == 0:
        word = 1
    r[0] = word
    for i in range(1, deg):
        hi, lo = divmod(word, 127773)
        word = 16807 * lo - 2836 * hi
        if word < 0:
            word += 2147483647
        r[i] = word
    fptr, rptr = sep, 0
    def step():
        nonlocal fptr, rptr
        r[fptr] = (r[fptr] + r[rptr]) & 0xffffffff
        result = r[fptr] >> 1
        fptr = (fptr + 1) % deg
        rptr = (rptr + 1) % deg
        return result
    for _ in range(deg * 10):   # glibc smider de første 310 outputs væk
        step()
    while True:
        yield step()

g = glibc_random(epoch)   # epoch = det seed serveren lækkede i banneret
r1, r2 = next(g), next(g)
kode = epoch - (r1 % 10000) + (r2 % 10000)

Jeg har selv verificeret denne implementation byte-for-byte mod en rigtig glibc random() (kompileret et lille C-testprogram og sammenlignet output for samme seed) før den blev sat her. Send koden → match → system("/bin/sh") på nc …:1338.

🚩 Vis løsning & eksempel-flag

Flag: HKN{F0RBRYDELSE_B3TALER_S1G_1KK3}

Hvad du har lært

  • 'No section header'/'statically linked' kan være UPX; grep -a UPX er et sekunds tjek.
  • Et tids-seedet PRNG der printer sit eget seed er ikke en hemmelighed; genskab sekvensen.
  • Daemon-tråde dør med hovedtråden; join en output-drain-tråd eksplicit når du henter flaget over socket.

Hvor ses dette igen?

To bredt nyttige pointer. (1) En binær der "ser stripped ud" er tit bare PAKKET: UPX er suverænt mest almindelig, og grep -a UPX eller upx -d afslører/udpakker den på et sekund, hvorefter du har fuld debug-info. (2) En tilfældighedsgenerator seedet med time() er kun så uforudsigelig som angriberens viden om tidspunktet, og lækker programmet selv sit seed, er sekvensen fuldt bestemt. Bemærk desuden at sprogenes PRNG'er IKKE er ens: glibc's rand()/random() matcher ikke Pythons Mersenne Twister, så du skal genimplementere den rigtige algoritme.
