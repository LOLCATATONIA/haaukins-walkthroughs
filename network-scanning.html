Network Scanning

Find hosten med den søgte port og hent flaget. Ren recon.

ForensicsHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Trin for trin

nmap -sn -n <subnet>/24                    # host-discovery
nmap -Pn -n -p8080 --open <subnet>/24       # find hosten med 8080 åben
curl -s http://<ip>:8080/                    # flaget står i HTML

Dette er hele recon-pipelinen (start → scan → extract → submit) som gentager sig i alle lab-interne opgaver.

🚩 Vis løsning & eksempel-flag

Flag (per-instans): HKN{u3-7U-Lae4yx}

Hvad du har lært

  • nmap -sn → -p<port> --open → hent er fundamentet for lab-interne opgaver.
