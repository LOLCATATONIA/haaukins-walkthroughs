🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Hvad går opgaven ud på?

file pokemon.jpg afslører at filen trods .jpg faktisk er et ZIP-arkiv. Pak ud → et ægte JPEG med flaget skrevet i bunden.

file pokemon.jpg          # -> Zip archive data
cp pokemon.jpg pokemon.zip && unzip pokemon.zip   # -> porygon39.jpg
file porygon39.jpg        # -> JPEG image data
