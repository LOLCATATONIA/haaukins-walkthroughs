Hvad går opgaven ud på?

file pokemon.jpg afslører at filen trods .jpg faktisk er et ZIP-arkiv. Pak ud → et ægte JPEG med flaget skrevet i bunden.

file pokemon.jpg          # -> Zip archive data
cp pokemon.jpg pokemon.zip && unzip pokemon.zip   # -> porygon39.jpg
file porygon39.jpg        # -> JPEG image data
🚩 Vis løsning & eksempel-flag

Flag: HKN{p0ry60n_15_7h3_rul3r_0f_cyb3r_5p4c3}

Hvad du har lært

  • Kør altid file, endelsen siger intet om det faktiske format.
  • Samme klasse som Broken but not Lost: filtypen lyver.

Hvor ses dette igen?

En ZIP forklædt som JPEG er en variant af samme princip som Broken but not Lost: endelsen lyver. Når file siger et andet format end navnet, så behandl filen som dét format (omdøb og pak ud, eller carve med binwalk hvis der er flere formater lagt i forlængelse af hinanden). Mange formater, blandt andet ZIP, Office-dokumenter og APK'er, er i virkeligheden bare ZIP-arkiver i forklædning.
