Covert Channels: HTTP

Data skjult i store/små forbogstaver på HTTP-headere.

ForensicsHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Hvad går opgaven ud på?

Alle tre opgaver løses på samme capture.pcap. Start altid med protokol-hierarkiet, og saml bits/bytes i kronologisk rækkefølge:

tshark -r capture.pcap -q -z io,phs

HTTP-headernavne er case-insensitive (RFC 2616 §4.2), så stort/lille forbogstav kan bære 1 bit pr. header uden at ændre requesten. 8 faste headers = 1 byte pr. request.

Trin for trin

tshark -r capture.pcap -Y 'http.request && ip.dst==100.117.87.84' -T text -V   # se casing

For hver request, i headernes faste rækkefølge: stort forbogstav = 1, lille = 0 → 8 bit → ét ASCII-tegn. 20 requests = 20 bytes.

Faldgrube: filtrér ikke på ordet "Request" — headeren upgrade-insecure-requests indeholder selv "request".

🚩 Vis løsning & eksempel-flag

Flag: HKN{3nc0d3d_1n_c4ps}

Hvad du har lært

  • Covert channels bor i felter der kan variere frit — her header-casing.
  • Opgaveteksten hinter om feltet (’RFC 2616 §4.2’).
