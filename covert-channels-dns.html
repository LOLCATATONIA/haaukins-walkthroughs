Covert Channels: DNS

Data smuglet ud som hex forrest i DNS-opslag.

ForensicsHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Hvad går opgaven ud på?

Alle tre opgaver løses på samme capture.pcap. Start altid med protokol-hierarkiet, og saml bits/bytes i kronologisk rækkefølge:

tshark -r capture.pcap -q -z io,phs

En kompromitteret host slår mærkelige domæner op. Dataene ligger som hex forrest i hvert subdomæne hos canarytokens.com.

Trin for trin

tshark -r capture.pcap -Y 'dns.flags.response==0 && dns.qry.name contains "canarytokens"' \
  -T fields -e frame.time_relative -e dns.qry.name

Sortér på tid, tag hex-labelen fra hvert navn, og afkod: 484b4e7b → HKN{, 77333172 → w31r … 7d → }.

🚩 Vis løsning & eksempel-flag

Flag: HKN{w31rd_5ubd0m41n5}

Hvad du har lært

  • DNS-exfiltrering pakker data i opslags-navne til en server angriberen styrer.
  • Saml altid i tidsrækkefølge (ikke alfabetisk).
