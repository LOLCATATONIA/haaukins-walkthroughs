Git logs

En 'fjernet' hemmelighed ligger stadig i commit-historikken.

ForensicsHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Trin for trin

sshpass -p haaukins ssh -o StrictHostKeyChecking=no user@<ip>
git -C ~/project log --oneline        # commit "Removed password from main.go" peger på stedet
git -C ~/project log -p --all | grep -aoE '(HKN|DDC)\{[^}]*\}'

Samme kerneidé som IaC privatekey: en slettet hemmelighed er stadig i historikken. Commit-beskeder ("Removed password…") peger direkte på de interessante commits.

🚩 Vis løsning & eksempel-flag

Flag (per-instans): HKN{A3-nl-woElDW}

Hvad du har lært

  • git log -p --all viser alle diffs i hele historikken (alle branches).
  • Commit-beskeder lækker hvor hemmeligheder blev 'fjernet'; gitleaks/trufflehog automatiserer.
