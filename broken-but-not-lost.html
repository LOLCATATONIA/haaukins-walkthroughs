Broken but not Lost

Filen er ikke i stykker — filnavnet lyver bare.

🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Hvad går opgaven ud på?

Fil: evidence/corrupted/01-3xt — del af forensics_dcis-osint.zip fra Introduction-opgaven.

En "ødelagt" fil 01-3xt. Men file læser de faktiske magic bytes:

file 01-3xt            # -> JPEG image data   (navnet løj!)
cp 01-3xt 01.jpg       # åbn -> flaget står skrevet i billedet
🚩 Vis løsning & eksempel-flag

Flag: HKN{1mp0rt4nc3_0f_3xt3nsi0ns}

Hvad du har lært

  • file læser magic bytes og afslører det faktiske format uanset endelse.
  • "Korruption" er tit bare et vildledende navn, selve opgavens pointe her.

Hvor ses dette igen?

En filendelse er bare en del af navnet, den fortæller intet sikkert om indholdet. Derfor er file (som læser de faktiske magic bytes) et af de allerførste værktøjer at nå efter, når du får en ukendt eller "ødelagt" fil. Samme pointe går igen i dotsuffix (en ZIP forklædt som JPEG). Gør det til en refleks: kør file før du tror på navnet.
